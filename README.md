# NUMBIS 2000

- Sitio estático original: `index.html`, `CSS/`, `IMAGENES/`
- Versión Node.js + MySQL: carpeta `numbis2000node/`

## Cómo levantar la versión Node
1. `cd numbis2000node`
2. `npm install`
3. `sudo mysql < db/ejercicio1.sql`
4. `sudo mysql < db/usuario.sql`
5. `npm start` y abrir http://localhost:3000
